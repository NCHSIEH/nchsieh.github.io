快速入門

  1. 在「課程管理」建立課程，填寫代碼、名稱與學期。
  2. 把講義 PDF 放進 repo 的 assets/courses/ 並 push 到 GitHub。
  3. 回到課程列，點「講義與作業」加入檔案路徑與截止日。
  4. 學生註冊並完成 Email 驗證後，到「學生管理」→「審核佇列」核准。

連線狀態

Email 提醒（EmailJS）

公告的「Email 提醒」功能透過 EmailJS 寄送，完全在瀏覽器端運作、不需要後端伺服器，免費方案為每月 200 封。 設定方式：註冊帳號 → 連接你的信箱 → 建立一組 Email Template → 把 Service ID／Template ID／Public Key 填入 assets/js/config.js 的 EMAILJS_SERVICE_ID／EMAILJS_TEMPLATE_ID／ EMAILJS_PUBLIC_KEY，push 到 GitHub 後即可使用，詳細步驟見 FIREBASE_SETUP.md。

修改登入密碼

修改後這台裝置與其他裝置都需要用新密碼重新登入。 若忘記目前密碼，請改用登入頁的「忘記密碼」流程。

講義檔案放置方式

講義 PDF 直接放進 GitHub repo 的 目錄， 在課程的「講義與作業」中填入相對路徑即可。

請注意：放在 repo 的檔案本身是公開的，知道完整網址的人都能下載。 審核機制控制的是「誰看得到檔案清單」，而不是檔案本身的存取權。 若有機密講義不宜外流，請勿放入 repo。

怎麼產生金鑰？（第一次使用請展開）
  1. 開啟 GitHub 金鑰產生頁面 ↗（需先登入 GitHub）
  2. Token name 隨意填，例如 course-upload
  3. Expiration 建議選 90 天或 1 年，到期後重新產生即可
  4. Repository access 選 Only select repositories，然後只勾選 nchsieh.github.io
  5. Permissions → Repository permissions → 找到 Contents，設為 Read and write
  6. 其他權限全部保持 No access
  7. 按 Generate token，複製那串 github_pat_... 貼回上面欄位

這組金鑰只能修改這一個公開網站的內容，動不了你的其他儲存庫，也讀不到任何私人資料。 金鑰只會顯示一次，關掉頁面就看不到了，記得當下就複製。
