快速入門

  1. 在「課程管理」建立課程，填寫代碼、名稱與學期。
  2. 把講義 PDF 放進 repo 的 assets/courses/ 並 push 到 GitHub。
  3. 回到課程列，點「講義與作業」加入檔案路徑與截止日。
  4. 學生註冊並完成 Email 驗證後，到「學生審核」核准。

講義檔案放置方式

講義 PDF 直接放進 GitHub repo 的 目錄， 在課程的「講義與作業」中填入相對路徑即可。

請注意：放在 repo 的檔案本身是公開的，知道完整網址的人都能下載。 審核機制控制的是「誰看得到檔案清單」，而不是檔案本身的存取權。 若有機密講義不宜外流，請勿放入 repo。

資料備份

匯出包含課程、講義、作業、公告與學生名單的完整 JSON 快照。建議每學期執行一次。

講義與作業僅限通過審核的學生讀取。
