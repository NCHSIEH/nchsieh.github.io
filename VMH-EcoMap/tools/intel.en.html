How updates work

Where the data file comes from:All content on this page is already embedded in this HTML file, so a single file can be opened offline. intel_data.json is an “update package” of the same data, stored in the Tool Scripts/ folder.
Automatic (no action needed):The “monthly intelligence schedule” runs automatically in the cloud on the 1st of every month: it re-verifies each item online (regulatory timeline changes, new vendor moves, updated data), then writes the new HTML and intel_data.json directly back to the 01_Analysis Tools/ folder — the next time you open the file, it’s already updated. If the computer was offline at the time, the update file is sent to the workspace conversation instead; just save it back to the folder to overwrite the old file.
Why there is no “one-click re-verify” button on the page:Re-verification requires searching the web and evaluating sources, which is beyond what a single HTML file in a browser can do (this page has no server and is not connected to the internet); so “generating new data” is handled by the cloud schedule, while the page’s job is to “display, load, edit, and export.”
Manual load:The “⟳ Load updated data” button in the top right can load a new intel_data.json at any time, redrawing the whole page instantly; this happens locally only and nothing is uploaded.
In-page editing:No need to wait for the schedule or edit JSON — click “✎ Edit data” in the top right to modify any field, or add or remove items, directly on the page. When done, click “⬇ Export data file” to download a new intel_data.json; put it back in the Tool Scripts/ folder to overwrite the old file, and anyone who loads it afterward will get your edited version.
Honesty principle:Items that could not be found are labeled “Not found,” estimates are labeled “Estimated” — figures are never fabricated; every entry includes a source and a verified date.
Edit mode: any text inside a dashed box can be clicked and edited directly; “✕ Delete” removes that entry, “+ Add” adds a new one. When done, click “✓ Finish editing” in the top right, then “⬇ Export data file” to save it as a new intel_data.json.
