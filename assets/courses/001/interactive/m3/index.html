非監督式學習：分群與降維

沒有標準答案的學習。問的不是「會怎樣」，而是「這裡面有什麼結構」。每一節都可以親手跑演算法：一步步看 K-Means 收斂、切樹狀圖、調 DBSCAN 的半徑、轉動 PCA 的座標軸。

  1. 說明為什麼分群前一定要縮放，並用自己的實驗數字佐證　第 02 節

前處理：縮放是必要的

SCALING IS NOT OPTIONAL

對應講義 M3：第 9–13 頁（PART 02、03）

監督式學習中，縮放「看演算法而定」；非監督式多數技術靠距離運作——不縮放等於白做。

① 哪些欄位要納入ID 類一律移除；與分群目的無關的也移除，放越多不代表分得越好
② 類別欄位怎麼處理K-Means 只吃數值；二元用 0/1，多類別用 One-Hot（但會拉高維度）
③ 用哪一種縮放Z-Score 是預設；Min-Max 需要固定範圍時用，但離群值會壓縮其他點

分群結果怎麼解讀

CLUSTER PROFILING · 命名與行動

對應講義 M3：第 39–43 頁（PART 09）

跑出群組只是一半的工作。說不出「每一群是誰」、該做什麼，這個分析就沒有價值。

① 看群大小極小的群（< 5%）是真的次族群還是雜訊？
② 群組剖析各群在各特徵的平均與整體平均比較
③ 為每群命名2–6 個字：「高齡低支出型」
④ 對應到行動兩群處置一樣 → 分開就沒有意義
