非監督式學習 101

UNSUPERVISED LEARNING BASICS

監督式問「這一筆會怎樣」，非監督式問「這一堆裡面有什麼結構」。沒有答案可以對，所以最終判準一定包含人的專業判斷。

分群 Clustering把相似的個案分成幾群：病人分型、照護路徑設計 → M3 主軸
降維把很多欄位壓成少數幾個：量表降維、高維檢驗值視覺化 → M3 主軸
異常偵測找出不像其他人的個案：生理訊號異常、異常申報 → M3 概念、M4 實作
關聯規則找出常一起出現的組合：共病、用藥組合 → M4

前處理：縮放是必要的

SCALING IS NOT OPTIONAL

監督式學習中，縮放「看演算法而定」；非監督式多數技術靠距離運作——不縮放等於白做。

① 哪些欄位要納入ID 類一律移除；與分群目的無關的也移除，放越多不代表分得越好
② 類別欄位怎麼處理K-Means 只吃數值；二元用 0/1，多類別用 One-Hot（但會拉高維度）
③ 用哪一種縮放Z-Score 是預設；Min-Max 需要固定範圍時用，但離群值會壓縮其他點

08

分群結果怎麼解讀

CLUSTER PROFILING · 命名與行動

跑出群組只是一半的工作。說不出「每一群是誰」、該做什麼，這個分析就沒有價值。

① 看群大小極小的群（< 5%）是真的次族群還是雜訊？
② 群組剖析各群在各特徵的平均與整體平均比較
③ 為每群命名2–6 個字：「高齡低支出型」
④ 對應到行動兩群處置一樣 → 分開就沒有意義

群組剖析與命名工作台

核心互動
