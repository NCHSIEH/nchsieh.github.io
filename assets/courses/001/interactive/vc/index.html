Vibe Coding 專班

六週，從一句話做到一個別人打得開、接得下去的小工具。貫穿全程的實例是長照給付試算器：W1 寫出規格、W2 修好三個錯、W3 驗證它是對的、W4 推上 GitHub 並上線、W5 處理資料、金鑰與成本、W6 交接與發表。
