為什麼這門課用 AI Studio

A SCAFFOLD FOR CONCEPTS

AI Studio 不是「Python 的替代品」，是「學概念的鷹架」。護理與健康科技背景的你，要學的是「怎麼判斷」，而不是「怎麼寫迴圈」。

① 把注意力留給方法初學者常卡在縮排、套件安裝、版本不相容——這些跟資料科學一點關係都沒有
② 流程視覺化＝思路視覺化Python 的流程藏在程式碼順序裡；AI Studio 的流程畫在畫布上，資料現在在哪一眼就看得到
③ 概念可完整遷移學會 Set Role 就懂 y = df['label']；學會 Cross Validation 子流程就懂 cross_val_score()

除了畫布之外的三大工具

TURBO PREP · AUTO MODEL · DEPLOYMENTS

Auto Model 可以用來建立基準線，但作業與專題必須自己拉流程——這門課要學的是「為什麼這樣做」，不是「怎麼按到結果」。Turbo Prep 改完記得一鍵轉成 Process。

Turbo Prep 互動式資料準備像 Excel 一樣看資料改資料；★ 改完要轉成 Process，否則無法重現
Auto Model 自動建模自動試多種演算法並比較；★ 適合建立基準線，別直接交作業
Deployments 模型部署發佈成服務、排程、REST API；免費版有功能限制
