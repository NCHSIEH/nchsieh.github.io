四種生成式架構

GAN · VAE · DIFFUSION · TRANSFORMER

另外三種在影像與科學資料上仍是主流，但所有主流 LLM 的底層都是 Transformer——本課程接下來全部聚焦在它。

GAN生成器造假、鑑別器抓假，對抗變強。多用於局部影像修補與合成訓練資料
VAE壓縮到潛在空間再解碼。主要用在異常偵測與科學資料降維
Diffusion從純雜訊開始一步步去噪。影像生成主流（DALL·E、Stable Diffusion）
★ Transformer注意力機制、預測下一個 token。所有主流 LLM 的底層

Attention：一句話說完它在做什麼

ATTENTION IS ALL YOU NEED

對句子中每一個詞算一個權重，權重高＝關聯強。舊做法（RNN）一個字一個字讀，讀到「他」時前面的「病人」已經模糊；Attention 一次看全部，距離多遠都不衰減。代價：計算量隨長度平方成長。

幻覺：為什麼它不是 bug

HALLUCINATION

它挑的是「最像下一個字的東西」，不是「事實上正確的東西」。你不可能用提示詞「關掉」幻覺——只能用 RAG 提供事實、用程式碼接管數值、用人工覆核把關。這正是 M8 整個模組在做的事。
