04

讀懂模型輸出

R² · F 檢定 · t 檢定 · 信賴區間

看區間不看點估計。統計顯著（p < 0.05）與臨床重要（效果夠大）是兩回事——樣本夠大時，微不足道的效果也會顯著。

F 檢定（整體）整個模型是否比「只用平均值」好？顯著不代表每個變數都有用
t 檢定（個別係數）係數是否顯著不為 0？不顯著 ≠ 沒關係，可能只是樣本不夠
信賴區間不含 0 即顯著；區間寬代表估得不準
p 值在「真的沒關係」的前提下看到這麼極端資料的機率——不是效果大小

多元迴歸與共線性

MULTIPLE REGRESSION · COLLINEARITY

加入更多變數，係數就從「總效果」變成「其他不變下的淨效果」。但若兩個變數講的是同一件事，係數會不穩甚至翻正負。

係數：總效果 → 淨效果給定其他納入變數後的條件關聯
R² 只升不降變數多的模型互比，改看調整後 R² 或交叉驗證
變數選擇前向、後向、全放、領域先驗——醫學研究以領域先驗為主
共線性診斷相關矩陣、VIF > 10、係數單獨 vs 同時納入翻正負

350 人訓練、150 人測試。點欄位放進或拿出模型，看係數、信賴區間與測試 RMSE 怎麼變；或按「逐步加入」看電腦怎麼挑。

這一步做錯會怎樣：在共線性下解讀個別係數，係數正負可能只是抽樣的偶然；變數數不同的模型直接比 R²，永遠會選到最複雜的那個。

正則化迴歸

RIDGE · LASSO · ELASTIC NET

變數多、樣本不多、又彼此相關時，給係數加一條韁繩反而讓模型更穩。正則化前必須標準化；λ 用交叉驗證選。

Ridge（L2）係數平方和懲罰：壓小但不歸零，對共線性特別有效
Lasso（L1）係數絕對值懲罰：把不重要的壓到 0＝自動選變數
Elastic Net兩者混合；AI Studio GLM 的 alpha：0＝Ridge、1＝Lasso

信賴區間 vs 預測區間

CONFIDENCE VS PREDICTION INTERVAL
