01

n8n 是什麼：六個核心概念

NODE · WORKFLOW · TRIGGER · CREDENTIAL · EXECUTION · EXPRESSION
工具全景與 n8n／Dify 選型見 M8 第 19 節 →

一個「用畫的」自動化平台：把不同服務串接起來，中間可以放邏輯判斷，也可以放一顆會思考的 AI Agent。共同骨架：Trigger（什麼時候）→ 抓資料或接收事件 → 判斷／處理 → 輸出或通知。

n8n 是開源可自架（fair-code）；400＋內建節點；原生支援 AI Agent；邏輯太複雜時有 Code 節點救援
n8n 不是不是資料庫；不是專門的 LLM 應用平台（RAG 不如 Dify 精緻）；自架版不是零維運

這個症狀，跟哪個概念有關？

資料怎麼在節點之間流動：Item 與 Expression

EVERY NODE RUNS ONCE PER ITEM

每個節點輸出的都是一個陣列，裡面是一筆一筆的 item；節點會對每一筆 item 各執行一次——上一步輸出 10 筆，下一個 HTTP Request 就被呼叫 10 次。看到中括號 [ ]，取值就要加索引。

核心互動
