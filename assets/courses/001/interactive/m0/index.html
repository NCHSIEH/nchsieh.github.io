02

監督式與非監督式

SUPERVISED VS UNSUPERVISED · 從資料長相就分得出來

判斷方式只有一個：你的資料裡有沒有「答案」那一欄（y）。有＝監督式，沒有＝非監督式。

x 變數＝特徵＝輸入月費、方案、使用時數——兩種學習都需要
y 變數＝標籤＝目標「是否取消」只有監督式才有
監督式在做什麼用歷史資料學出 x → y，再預測新個案
非監督式在做什麼沒有答案可學，改問「哪些個案彼此相似」

03

技術演進：1958–2026

FROM STATISTICS TO AGENTS

今天的每一個技術名詞，都是為了解決前一代做不到的事而出現的。推力只有三個：資料變多、算力變便宜、演算法有突破。

1960s–70s資料是「樣本」統計推論、假設檢定；資料少而貴，靠抽樣
1980s資料是「紀錄」關聯式資料庫與 SQL；大量累積，但只用來查
1990s資料是「資產」資料倉儲、KDD、CRISP-DM；電腦開始「找」假設
2000s–今資料是「原料」集成學習、大數據，到深度學習與 Agent

專案界定：六步驟寫成一頁

SCOPING A PROJECT

專案不是從資料開始，是從一個界定清楚的範圍開始。走完六步通常只要一兩小時，卻能省下數週走錯方向的時間。

① 站在使用者角度他在乎什麼？什麼指標對他重要？
② 腦力激盪問題先別想資料，盡量想大
③ 腦力激盪解法資料科學只是其中一種選項
④ 決定技術監督式還是非監督式？
⑤ 釐清資料需求結構、特徵、來源與範圍
⑥ 彙整範圍與目標寫成一頁給使用者確認
