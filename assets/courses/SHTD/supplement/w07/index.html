智慧醫療與科技發展　W7　AI Agent 與臨床流程自動化　·　導讀與延伸閱讀（2026-11-22）

讓 AI 去「做事」之前，要先決定什麼？

上週 AI 寫錯，醫師改掉就好；這週 AI 會動手做事——查資料、填表、送轉介。本週學會判斷：哪些事交給 Agent、人站在哪裡、出錯時怎麼停，以及為什麼常常應該先再造流程，再自動化。

白話導讀練習資料延伸閱讀自我檢核

白話導讀

頁碼為講義頁腳頁碼（學生版與教師版相同）。

1. Agent 是什麼，不是什麼講義 p.6–12

Agent ＝ LLM（大腦）＋工具（手）＋記憶＋規劃，能「思考 → 行動 → 觀察」反覆進行。它不等於 RPA（照固定腳本點按），也不等於聊天機器人（只給建議）。市場上有不少「Agent 洗白」。

醫療的原則：能用固定工作流解決的，就不用 Agent；外層用確定性流程鎖住安全步驟，內層局部節點才呼叫權限受限的 Agent。

來源：Anthropic（2024-12）. Building Effective Agents

2. 每一步都對，串起來就不一定對講義 p.15–16

MedAgentBench 在模擬電子病歷中測試：最佳模型成功率約 70%，查詢類較高、寫入類（下醫囑）較低。若每一步成功率 95%，串 10 步全對只剩約 60%——交接越多，錯誤越可能在交接處發生。

來源：Jiang 等 MedAgentBench（arXiv）

3. 人在哪裡：決策權限矩陣講義 p.18–19

用兩個問題決定 AI 可以做到哪裡：影響大不大？做錯能不能撤回？

可撤回難撤回
影響小自動執行（整理文件、預填表單）執行後通知（寄出衛教簡訊）
影響大人核准後執行（送出轉介）禁止 AI 執行（變更處方、告知預後）

同一個 Agent 可以混用「人在迴圈中／上／外」三種模式，依每個動作分別設定。

4. Agent 會怎麼出錯講義 p.20–23

五種常見失誤：工具誤用、資訊過時、目標錯置、權限越界、被提示注入。nH Predict 案例顯示：當演算法輸出被當成「決定」，人就從迴圈消失。EchoLeak 則提醒：Agent 讀到的外部內容一律要當成「資料」，不是「指令」。

來源：OWASP Top 10 for LLM Applications 2025

5. 先再造，再自動化講義 p.25–28

Project RED 是沒有 AI 的出院流程再造，就讓 30 天急診與再入院顯著下降約 30%。台灣出院準備銜接長照從平均 51 天縮短到 4 天，也是先把評估前移到住院中。AI Agent 的價值，常常在流程再造之後的「施力點」：首日篩選、跨系統預填、進度追蹤。

來源：Jack 等 2009 Project RED；衛福部：出院準備銜接長照

W07_出院流程任務紀錄.csv下載

一位模擬病人從「決定出院」到「長照服務第一次到宅」的 14 筆任務紀錄（開始、完成時間、負責角色、等待原因）。

  1. 算出每筆任務的「實際處理時間」與「等待時間」。總時程中，等待占幾成？
  2. 找出等待最久的三段：它們卡在資訊、交接、還是核准？
  3. 哪一段適合交給 Agent？哪一段應該先改流程（例如評估前移），而不是自動化？

自我檢核

  1. 給一個 Agent 動作，能用決策權限矩陣判斷它屬於哪一格。
  2. 能說明為什麼「每步 95% 成功率」串起來會變低。
