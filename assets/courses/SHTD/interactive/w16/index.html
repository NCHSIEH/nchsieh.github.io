從「算得對」到「真的有幫助」：證據階梯與 NICE 分層

ANALYTICAL → CLINICAL VALIDATION → CLINICAL UTILITY · NICE ESF TIERS A / B / C

很多產品停在第一層就宣稱「準確率 95%」。證據要求應與風險相稱：風險越高，證據要求越多。

第二層

第三層
臨床效用
