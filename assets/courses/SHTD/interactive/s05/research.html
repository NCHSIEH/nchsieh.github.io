一、研究方法與 ANCOVA 核心估算公式

為同時排除期中考／排班週期之自然波動與高壓受試者之均值回歸（Regression to the Mean），並確保對照組受試者於第 15 天後測完成後獲得同等正念音檔資源，本研究採 1:1 分層區集隨機（Block Size = 4）等候名單對照設計，並以中心化基線分數為共變數建立一般線性模型：

Y_{i,post} = β₀ + β₁ · Group_i + β₂ · (Y_{i,pre} − Ȳ_pre) + ε_i
β̂₂ = S_{xy,within} / S_{xx,within} = 707.3048 / 1095.3952 = 0.6457
β̂₁ = (Ȳ₁ − Ȳ₀) − β̂₂ · (X̄₁ − X̄₀) = −3.4595 − 0.6457 × (1.0095) = -4.1114

三、快速重現步驟（零外部套件依賴）

  1. 解壓縮 S05_research_kit.zip 後開啟終端機切換至該資料夾。
  2. 執行 python check.py：自動驗證 72 人篩選表、64 人隨機表、PSS-10 反向題稽核與全套 ANCOVA / ITT 指標。
  3. 執行 python analyze.py：檢視完整 JSON 報表（含斜率同質性檢定 interaction_p = 0.8462 與 2,000 次拔靴信賴區間）。
  4. 開啟 我的研究計畫.md 填入研究對象、介入規格與預設主要指標。
